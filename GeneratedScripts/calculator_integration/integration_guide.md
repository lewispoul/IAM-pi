# Guide d'intégration pour calculator

# Instructions d'intégration

1. Créez un nouveau projet Flask ou ajoutez ce code à un projet existant.
2. Ajoutez les endpoints Flask dans votre fichier principal de l'application Flask (par exemple, `app.py`).
3. Placez le code HTML dans un fichier `templates/calculator.html` dans votre projet Flask.
4. Assurez-vous que Flask est configuré pour servir les fichiers statiques et les templates.
5. Lancez votre application Flask en exécutant `flask run` dans le terminal.
6. Accédez à l'interface utilisateur de la calculatrice via votre navigateur en naviguant vers l'URL appropriée (par exemple, `http://localhost:5000/calculator`).

## Fichiers générés:
- Endpoints: GeneratedScripts/calculator_integration/calculator_endpoints.py
- Interface: GeneratedScripts/calculator_integration/calculator_interface.html
- Module original: GeneratedScripts/calculator.py
